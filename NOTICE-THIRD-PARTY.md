# Aviso de componentes de terceiros

O CajuOS distribui componentes derivados do ecossistema UniFrog e cores com licenças individuais. Não há uma licença única implícita para todos os arquivos deste repositório. Consulte `overlay/unifrog/LICENSE.txt`, `overlay/unifrog/THIRD_PARTY.md` e os avisos de cada componente antes de redistribuir partes separadamente.

Este repositório não distribui ROMs comerciais, BIOS proprietárias ou saves pessoais.
